# mba-quantum-commerce-cache

Cache das chamadas ao Claude usadas no projeto integrado da disciplina Knowledge Management and Prompt Engineering (MBA FIAP).

- `cache_llm.json`: respostas do gerador, do juiz, do roteamento, da extração de fatos e do agente, indexadas pelo hash do prompt.
- `ragas_resultados.json`: valores do RAGAS da linha de base e da configuração final.

O notebook do projeto baixa estes arquivos pelo link raw para reproduzir exatamente os números do relatório. Não há chaves nem dados pessoais aqui, só textos dos chamados e dos documentos fornecidos pela disciplina.
